# Instructions on how to compile, run, and start the chess game.
# 1. Boot up the program by running it
# 2. White player makes first move by dragging and dropping a piece to a valid location
# 3. Then play on like a normal chess game

# Achieved features in the makings of this Chess Project
# 1. Ability to change the colors of the squares on the chess board (light & dark)
# 2. Ability to change the colors of the pieces on the chess board (white & black)
# 3. Supports chess rules such as Castling, En Passant, and Pawn promotion to Queen
# 4. Lets the user know when the game is over by indicating a checkmate message
# 5. When a king is in danger (check), that square is highlighted in red
# 6. A graveyard which includes all captured pieces made by the player
# 7. Includes dynamic board size changes
# 8. Ability to create new games which factory resets a chess game to its original status
# 9. Ability to save chess games for later using Save Game
# 10. Ability to load previous save files to keep the same colors and size as before
# 11. An Undo button to see different outcomes as well as if you made a critical mistake in a chess game
# 12. Ability to see all move history in terms of coordinates eg. B1 -> C3
